# 프로젝트 설명 가이드

## 30초 소개

Python으로 논문과 쇼핑몰 정보를 수집해 표로 정리했고, 생성형 AI로 개인용 미니게임도 구현했습니다. 페이지 구조와 요청을 확인하고 누락된 항목을 처리하면서 데이터 수집의 기본 흐름을 익혔습니다. AI가 만든 코드도 실제 응답과 화면을 보며 수정해야 한다는 점을 배웠습니다. 전공 데이터의 통계적 해석은 별도의 반도체 공정 분석 프로젝트에서 정리했습니다.

## 설명할 수 있어야 할 질문

- RISS에서 파라미터를 딕셔너리로 관리한 이유는?
- 순서 기반 선택자와 항목명 기반 탐색은 어떻게 다른가?
- 주제어가 없는 논문은 어떻게 처리했는가?
- Selenium을 사용한 이유와 스크롤 종료 조건의 한계는?
- 120건은 무엇을 센 숫자인가? → 저장된 데이터 행이며 고유 상품 수가 아님.
- AI가 만든 부분과 직접 판단·수정한 부분은?
- 게임에서 엔딩 조건 두 개가 겹치면 어떤 엔딩이 우선하는가?
- 공개용 테스트와 최초 프로젝트 경험은 어떻게 다른가?

## 자소서에 쓸 수 있는 표현

“Python과 생성형 AI를 활용해 논문·상품 정보를 수집하고 구조화했습니다. 실제 요청과 HTML 구조를 확인하며 추출 방식을 수정하고 누락 항목을 처리했습니다.”

“생일 축하 미니게임의 방향을 기획하고 AI로 구현한 코드와 화면을 수정했습니다. 프로그래밍 지식을 바탕으로 선택 흐름과 화면 배치를 검토했습니다.”
