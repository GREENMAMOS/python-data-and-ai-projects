# 동적 쇼핑 페이지 데이터 수집

## 목적과 결과

스크롤에 따라 추가되는 상품 정보를 수집해 비교 가능한 표로 저장했습니다. 
수집 결과: 120행 × 5개 필드

수집 항목은 상품명·상세페이지링크·가격·판매처·배송정보입니다. 가격의 쉼표와 원 표시, 배송정보의 공백 등을 정리하고 pandas DataFrame을 엑셀로 저장했습니다.

## 처리 흐름

`Selenium 페이지 열기 → 최대 5회 스크롤 → 높이 변화 확인 → page_source 파싱 → 필드 추출·정리 → DataFrame → Excel`

원본에서는 스크롤 후 1초 대기하고 페이지 높이가 같으면 종료했습니다. 네트워크가 느린 경우 더 불러올 데이터가 있어도 종료될 수 있으므로 전체 수집 보장 방식은 아닙니다. 포트폴리오에서는 이 한계를 함께 설명합니다.

## 원본과 공개용 정리의 차이

- 원본 경험: Selenium 스크롤, CSS 선택자, 가격 문자열 정리, 표 생성과 엑셀 저장
- 이번 정리: 함수 분리, 가격 정수 변환, 필수 항목 누락 시 명시적 오류, 브라우저 종료 처리, 합성 HTML 기반 테스트

## 역량 설명

정적 요청만으로 얻을 수 없는 데이터를 브라우저에서 불러오는 과정과, 화면의 문자열을 일정한 필드의 표로 정리하는 과정을 경험했습니다. 상품 가격의 차이를 설명하는 통계·시장 분석을 수행한 프로젝트로 확대 해석하지 않습니다.
