# RISS 논문 정보 수집

## 목적

검색 결과의 제목·링크와 상세페이지의 발행기관·발행연도·주제어를 모아 문헌을 비교하기 쉽게 정리하는 실습입니다. 원본 노트북의 검색어는 `패션 인공지능`입니다. 배터리·소재 논문을 자동 분석한 실적이나 논문 본문 요약 기능으로 소개하지 않습니다.

## 원본에서 수행한 내용

1. 개발자도구 Network에서 검색 요청의 Query String Parameters 확인
2. 검색어·페이지·출력 개수 등을 딕셔너리로 구성해 `requests.get(..., params=...)`에 전달
3. `.srchResultListW > ul > li`에서 제목과 상세 링크 추출
4. 상세페이지를 요청하고 발행기관·발행연도·주제어 추출
5. 항목 순서 기반 선택자에서 항목명 기반 탐색으로 변경, 없는 주제어는 빈 목록으로 처리

## 문제 해결에서 배운 점

HTML을 가져오는 것과 원하는 데이터를 얻는 것은 다릅니다. 실제 응답과 화면 구조를 비교하고, 요청 Header와 selector를 확인했습니다. AI는 코드와 오류 원인 탐색을 도왔지만 추출한 값이 필요한 항목인지는 실행 결과로 확인했습니다. 세부 항목 순서가 달라질 수 있어 항목명 기준으로 찾는 방법을 연습했습니다.

## 공개용 정리

[collector.py](collector.py)는 원본 흐름을 함수로 분리한 버전입니다. 요청 timeout·HTTP 오류 확인, URL 결합, 누락 제목·발행기관·발행연도 처리, CSV 데모와 테스트는 이번 정리 단계에서 추가했습니다. 원본에 있던 SSL 인증 비활성화는 유지하지 않았습니다. 인증 오류는 인증서와 실행 환경을 확인해야 하며 검증을 끄는 것을 정상 해결로 소개하지 않습니다.

```python
params = build_params("패션 인공지능", page=1, page_size=10)
response = session.get(SEARCH_URL, params=params, timeout=20)
```

오프라인 데모는 `fixtures/`의 합성 예시를 사용합니다. 실제 RISS 검색 결과·논문 제목을 재배포하지 않으며, 현재 사이트에 대한 접속 테스트는 수행하지 않았습니다. 데이터 구조는 `title, url, publisher, year, keywords`입니다.
